# Nexo Drive URL directory

Hash routes work on GitHub Pages. Course and profile IDs in these URLs preserve the selected record on direct navigation and refresh. Portals and records remain frontend demonstrations.

Legacy detail URLs without an ID open the first example record. Public course URLs without a course parameter open Cars. Invalid IDs open the 404 page.
